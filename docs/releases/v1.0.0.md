Sir Thaddeus 1.0.0 is the first stable public release of the local-first AI
workspace and the beginning of the numbered release line.

## Core

- Run a local model through LM Studio, Ollama, or another OpenAI-compatible
  endpoint.
- Keep conversations, durable memory, Wiki content, routines, settings, and
  traces on your machine.
- Use permissioned web, file, document, Wiki, memory, screen, clipboard, and
  system capabilities through an audited boundary.
- Stop active turns and sidecar work from the desktop instead of waiting for an
  agent to finish.

## Desktop

- A workspace-backed conversation experience with a conversation library,
  Markdown rendering, source cards, work receipts, activity history, and
  diagnostics.
- Visible permission decisions and evidence confidence for consequential work.
- Direct model, context, voice, file-access, location, and appearance controls.

## Capability improvements

- Narrow deterministic date and time handling avoids unnecessary model calls.
- Wiki intent guards preserve state for hypothetical, negated, and deferred
  requests while keeping explicit immediate writes available.
- Application-owned default Wiki locations reduce argument mistakes without
  weakening custom-location or permission behavior.
- Verified answer-only projection and fail-closed local-file resolution turn
  successful tool evidence into more reliable final answers.
- Completion repair stops when a proposed repair is exactly unchanged, avoiding
  a redundant validation call.

## Research and trust

- The repository includes the benchmark harness, matched-control research
  method, promotion gates, negative results, and current evidence ledger.
- Model capacity, harness capability, and product quality are reported
  separately. Tool-enabled outcomes are not presented as closed-book model
  intelligence.
- Rejected routing, voting, and validation-removal experiments were removed
  rather than left behind as dormant production behavior.

## Downloads

The release publishes self-contained full bundles and SHA-256 checksums for:

- Windows x64
- Linux x64
- macOS Apple Silicon

Windows is the primary polished desktop target. Linux and macOS packages expose
the supported runtime, but their desktop ergonomics remain less mature.

## Before you launch

- Release binaries are currently unsigned, so Windows SmartScreen may warn on
  first launch.
- You supply the model endpoint; no hosted model account is bundled.
- Voice and local search increase the full-bundle download size and remain
  configurable.
- Review the [first-run guide](https://github.com/raydeStar/sir-thaddeus/blob/master/docs/FIRST_RUN.md)
  and [known limitations](https://github.com/raydeStar/sir-thaddeus/blob/master/docs/KNOWN_LIMITATIONS.md)
  before enabling sensitive capabilities.

Thank you for trying the first public release. Issues, experiments, and honest
failure reports are welcome.
